# Project CSN - A Marathon Towards My Cybersecurity Goals

## What is Project CSN?

Project CSN is my first real attempt at building a home lab with a set direction and clear purpose. An environment where I can learn about, practice, and experiment further on cybersecurity concepts, network and system administration as well as apply foundational concepts based on Lean Six Sigma methodologies, and further develop technical writing skills.
